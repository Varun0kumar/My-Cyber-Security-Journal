## 🔍 Investigation Approach

For each investigation, I follow a structured SOC workflow:

1. Alert Review & Understanding  
2. Log Analysis (Source, Destination, Timeline)  
3. Identifying Suspicious Indicators (IPs, domains, hashes)  
4. Threat Validation using tools (VirusTotal, ANY.RUN, etc.)  
5. Correlation of events across systems  
6. Final Verdict (True Positive / False Positive)  
7. Documentation of findings
